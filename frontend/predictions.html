Metrics Explanation

Metric Description
Correct Number of correct predictions out of total predictions made by the model on resolved events.
Accuracy Percentage of correct predictions. Calculated as (Correct / Total) * 100%.
Human Acc Market consensus accuracy on the same prediction points as the model. Human predicts YES if market probability > 50%, otherwise NO. This represents the "wisdom of the crowd" baseline.
vs Human Model accuracy minus human accuracy on the same predictions. Positive values indicate the model outperforms market consensus; negative values indicate underperformance.
Pred Value Prediction Value using log-return method. For correct predictions: -log(p), for incorrect: log(p), where p is the market probability for the predicted outcome. Higher values indicate more valuable predictions that beat market expectations.

Prediction Value Formula

If prediction is CORRECT: Value = -log(p)
If prediction is INCORRECT: Value = log(p)
where p = market probability for the predicted outcome at prediction time

Interpretation Guide

+ Positive Value
+0.1 ~ +0.7 Small gain (p ≈ 50%~90%). Model correctly predicted an outcome the market also favored. Reward is small since the market expected this too.
+0.7 ~ +2.3 Moderate gain (p ≈ 10%~50%). Model correctly made a contrarian prediction. Captured alpha by betting against market consensus.
+2.3 ~ +6.9 Exceptional gain (p ≈ 0.1%~10%). Model correctly predicted an outcome the market deemed very unlikely. High-value contrarian call.
− Negative Value
-0.1 ~ -0.7 Minor loss (p ≈ 50%~90%). Model predicted an outcome the market favored, but was wrong. Small penalty since the market was also fooled.
-0.7 ~ -2.3 Moderate loss (p ≈ 10%~50%). Model made a contrarian prediction that turned out wrong. Failed bet against market consensus.
-2.3 ~ -6.9 Severe loss (p ≈ 0.1%~10%). Model predicted an outcome the market deemed very unlikely, and was wrong. Failed contrarian bet.
Theoretical Bounds: Value ranges from -6.9 to +6.9, based on probability clamp [0.001, 0.999]. In practice, most values fall within ±2.3 (corresponding to p between 10% and 90%).
The final Pred Value shown is the average across all predictions with market probability data. A positive average means the model generates value beyond market consensus; negative means it underperforms.
